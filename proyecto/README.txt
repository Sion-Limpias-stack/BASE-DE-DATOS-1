Proyecto: Sistema de Gestión para Tienda de Electrónica 


Introducción
Como diseñador de esta arquitectura, concebí este sistema no solo como un repositorio de datos, sino como el motor operativo central del negocio. En un entorno dinámico como el comercio de electrónica en un mercado local, los principales retos son el control estricto de inventarios de alto valor, el rastreo de garantías y la gestión flexible de ventas al contado y a crédito (fiado).
Diseñé esta base de datos relacional para automatizar la trazabilidad completa del negocio, desde que un producto ingresa mediante un proveedor hasta que se vende, se cobra o se procesa por garantía.
